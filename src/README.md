src/ package

Contains the Python package code for this project.

Layout
- jailhouse/agents: Agent definitions and LLM decision logic
- jailhouse/simulations: Visual/algorithmic simulations (Ising, Prisoner's Dilemma grid)
- jailhouse/analysis: Reusable analysis utilities
- jailhouse/viz: Plotting helpers

Import notes
Scripts under scripts/ add src/ to PYTHONPATH at runtime for local development.
